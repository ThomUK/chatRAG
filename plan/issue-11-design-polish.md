## Acceptance criteria

- [ ] Typography: Inter font applied consistently at appropriate weights and sizes throughout; heading hierarchy is clear
- [ ] Whitespace: generous padding and margins throughout — nothing feels cramped
- [ ] Colour palette: light background, one muted accent colour used sparingly and consistently for interactive elements
- [ ] Buttons: considered, not default Bootstrap — correct size, weight, and spacing
- [ ] Tab navigation: clean and modern, not default Bootstrap tabs
- [ ] Chat bubbles: clearly distinguished user vs. assistant messages; sources block is visually separated and understated
- [ ] Context window visualiser pills: smooth slide-up CSS transition, correct colour/grey states, fade to white below the 3rd dropped message
- [ ] Modal: polished — correct padding, clear form layout, progress bar styled consistently
- [ ] Welcome screen: consistent with main app aesthetic
- [ ] Connect Your Own tab: form fields and confirmation states feel considered, not default
- [ ] The overall impression is: modern, professional, startup-grade — not a government tool, not default Bootstrap
